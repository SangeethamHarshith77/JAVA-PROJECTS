# ATM Management System

A simple console-based ATM program developed in Java as part of my programming practice.

This project focuses on applying basic Java concepts such as user input, variables, conditional statements, arithmetic operations, and `Scanner`.

## Features

- Accepts an initial account balance
- PIN verification
- Deposit functionality
- Withdrawal functionality
- Balance display
- Simple ATM menu
- Deposit confirmation
- Console-based interaction

## Technologies Used

- Java
- Java `Scanner`
- Conditional statements
- Variables and data types
- Arithmetic operations

1. Initial account balance
2. PIN
